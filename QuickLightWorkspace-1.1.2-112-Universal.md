# 轻量工作台 1.1.2（112）

- 默认升级源迁移至 Gitee / GitHub 的 QuickLightWorkspace 新仓库。旧版仍可从原 QLLaunch 入口获取本次更新，升级成功后使用新路径检查后续版本。
- 保留原应用标识、升级签名公钥和用户数据位置，无需重新安装或重建布局。
- 同步九种语言的界面与帮助翻译，精简窄菜单中的长译文。
- 精简软件更新窗口，移除初始操作提示、“升级说明”标题和多余留白，保留真实更新状态和进度。
- Apple Silicon / Intel 通用安装包，要求 macOS 14 或更新版本。

正式 1.1.0（106）及更新版本可在软件内升级。0.x 版本请退出旧版，下载完整安装包手动安装一次。

## English

- Updates now use the QuickLightWorkspace repositories on Gitee and GitHub. Older versions can still obtain this update through the original QLLaunch feeds; after upgrading, future checks use the new paths.
- Keeps the existing application identity, update signing key and user data locations.
- Updated all nine supported languages and shortened narrow-menu labels.
- Simplified the update window while preserving real status and progress.
- Universal Apple Silicon / Intel package. Requires macOS 14 or later.

Official version 1.1.0 (106) and later support in-app updates. Users of 0.x versions should quit the old app and install the full package manually once.
